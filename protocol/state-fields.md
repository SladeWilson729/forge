# State snapshot field sources

Generated against Forge 2.0.16-SNAPSHOT at commit f3ca67d17d

This table covers every property of the six requested definitions after task 1.2, plus nested commander and library fields. Sources are public APIs at this commit; no reflection or private property access is needed. See [schema.md](schema.md) for the wire contract. Read live Game/Card/Combat APIs only inside the same Forge-safe callback as snapshot construction, never on the socket writer.

Visibility labels apply only after deciding whether the object may be sent. `canBeShownTo` alone does not reveal face-down identity: also call `canFaceDownBeShownTo`; `mayPlayerLook` is the exceptional permission both predicates consult. An owner-only activeInput belongs only to its seat. A public zone/collection does not authorize sending hidden card fields. FaceDownCard uses current public characteristics without name/set/num; HiddenCard contains only its mapped opaque id and hidden=true.

Getter names in backticks in the getter column are the explicit, non-reflective call inventory checked by StateFieldProbeTest. Chained receivers are null-checked. Collection and game getters run on their applicable receivers; player getters run for all four players, and card getters for every live card in Hand, Battlefield and Command at turn 3. Stack views captured from actual cast events and the most recent actual Combat are retained until turn 3 so their getter families are exercised even when the current stack/combat is empty. This is a getter-liveness probe, not a positive-case test of every mechanic or a visibility correctness test.
